# Breaking Walls frontend aka `bw-frontend`

Provides the [Maze Builder](https://www.github.com/zmertens/MazeBuilder) application with a web interface.
It additionally is a fully-featured Voxel engine based off of [craft](https://www.github.com/fogleman/craft).
It is also a procedural level generator with model export capabilities.
It is a hobby project and has been my attempt at an ode to the magicians that built the C++ landscape (C also, but primarily focusing on the C++11 standards and onward).

## Build and Run

`npm i` and `npm run dev` or `npm run preview` to get things going.
